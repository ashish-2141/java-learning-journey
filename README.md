# Java Learning Journey

A 12-week self-paced Core Java plan, from Java basics to a console-based Workflow and Task Manager.

Follow the rule: **Understand → Predict → Code → Break → Debug → Test → Explain → Apply.**

## Roadmap

1. Java Syntax and Program Structure
2. Primitive Data Types and Type Conversion
3. Operators and Expressions
4. Control Flow Statements
5. Arrays and Strings
6. Classes, Objects, and Encapsulation
7. Immutability and Memory Management
8. Exception Handling
9. Collections Framework
10. Generics
11. Input and Output
12. Integrated Workflow and Task Manager

JDK 21 (Eclipse Temurin) is recommended. Each week is kept in its own folder with a separate `src/` tree so weeks can be compiled independently.
