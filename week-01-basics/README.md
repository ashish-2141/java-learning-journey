# Week 1: Java Syntax and Program Structure

Topics: class and method structure, statements, braces, semicolons, source-file naming, case sensitivity, `main`, command-line arguments, compilation and execution, JVM and bytecode, comments, identifiers, naming conventions, scope.

## Practice

- [ ] Print your name and education
- [ ] Print three career goals
- [ ] Create a formatted student profile
- [ ] Run `javac` and `java` from the terminal
- [ ] Try command-line arguments
- [ ] Explain class, method and block scope

## Mini-project

Build a Personal Profile Console Program with your name, education, skills, career objective and current learning goal.

## Checkpoint

Explain how Java source code becomes executable, why `main` is static on JDK 21, the difference between a class and a method, comment types, and scope.

## Compile and run

```bash
javac -d out/week01 $(find week-01-basics/src -name "*.java")
java -cp out/week01 com.example.week01.HelloWorld
```
