# Week 2: Primitive Data Types and Type Conversion

Study the eight primitive types, integer ranges, floating-point precision, `char`, Unicode, `boolean`, widening and narrowing conversions, numeric promotion, overflow, casting, and default values.

## Practice

- [ ] Store age, population, salary, distance and transaction IDs
- [ ] Compare `float` and `double`
- [ ] Explain why `0.1 + 0.2` may not equal exactly `0.3`
- [ ] Work with `char`, escape sequences and booleans
- [ ] Demonstrate widening and narrowing
- [ ] Print default values of instance fields

## Mini-project

Build a Student Result Calculator with five subject marks, total, percentage, pass/fail result and grade.

## Compile and run

```bash
javac -d out/week02 $(find week-02-data-types/src -name "*.java")
java -cp out/week02 com.example.week02.DataTypeExamples
```
