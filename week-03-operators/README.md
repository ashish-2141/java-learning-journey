# Week 3: Operators and Expressions

Study arithmetic, unary, increment/decrement, relational, equality, logical, short-circuit, assignment, ternary and bitwise operators. Learn operator precedence and numeric promotion.

## Practice

- [ ] Simple calculator
- [ ] Even/odd checker
- [ ] Unit and time conversion
- [ ] Eligibility conditions
- [ ] Maximum of two numbers
- [ ] Bit operations: set, clear and test a bit

## Mini-project

Build an Expression Laboratory that evaluates expressions with and without parentheses, demonstrates precedence, short-circuiting, and pre/post increment.

## Compile and run

```bash
javac -d out/week03 $(find week-03-operators/src -name "*.java")
java -cp out/week03 com.example.week03.OperatorExamples
```
