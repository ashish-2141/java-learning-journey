# Week 4: Control Flow Statements

Study `if`, `if-else`, `else-if`, nested conditions, guard clauses, traditional and modern `switch`, `for`, enhanced `for`, `while`, `do-while`, `break` and `continue`.

## Practice

- [ ] Largest of three numbers
- [ ] Leap-year checker
- [ ] Grade calculator
- [ ] Menu-driven calculator
- [ ] Multiplication tables, factorial and prime check
- [ ] Number guessing and digit reversal

## Mini-project

Build a Console Banking Menu with check balance, deposit, withdraw, view transactions and exit. Include input validation and repeated menu execution.

## Compile and run

```bash
javac -d out/week04 $(find week-04-control-flow/src -name "*.java")
java -cp out/week04 com.example.week04.SwitchDemo
```
