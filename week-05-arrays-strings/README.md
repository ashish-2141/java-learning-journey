# Week 5: Arrays and Strings

Study one- and two-dimensional arrays, jagged arrays, indexing, iteration, searching, sorting basics, String immutability, reference versus content comparison, the string pool, common String methods, StringBuilder and StringBuffer.

## Practice

- [ ] Sum, average, minimum and maximum
- [ ] Linear search and array reversal
- [ ] Matrix addition and transpose
- [ ] Explain `==` versus `.equals()`
- [ ] Palindrome, word counter, vowel counter and sentence analyser
- [ ] Use StringBuilder to build and reverse text

## Mini-project

Build a Text Analyzer that reports character count, word count, vowel count, digit count, most frequent character, reversed text and palindrome status.

## Compile and run

```bash
javac -d out/week05 $(find week-05-arrays-strings/src -name "*.java")
java -cp out/week05 com.example.week05.ArraysAndStringsExamples
```
