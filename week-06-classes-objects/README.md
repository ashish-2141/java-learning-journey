# Week 6: Classes, Objects, and Encapsulation

Study class structure, fields, methods, objects, constructors, declaration/instantiation/initialisation, references, null, static and instance variables, method overloading, `this`, access modifiers, getters, setters and validation.

## Practice

- [ ] Create classes with fields and methods
- [ ] Draw stack-and-heap diagrams
- [ ] Compare instance, local, parameter and static variables
- [ ] Demonstrate method overloading
- [ ] Build a visibility table for all four access levels
- [ ] Validate values in setters and constructors

## Mini-project

Build a Student Management Model with private fields, constructors, getters/setters, validation, result calculation and information display.

## Compile and run

```bash
javac -d out/week06 $(find week-06-classes-objects/src -name "*.java")
java -cp out/week06 com.example.week06.Student
```
