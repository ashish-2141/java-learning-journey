# Week 9: Collections Framework

Study the collections hierarchy, Iterable, Iterator, List, Set, Queue, Deque, Map, common implementations, iteration, sorting helpers, `equals()` and `hashCode()`.

## Practice

- [ ] Manage a list of students
- [ ] Remove duplicate names with a set
- [ ] Compare HashSet, LinkedHashSet and TreeSet
- [ ] Build a service-token queue
- [ ] Count word frequencies with a map
- [ ] Use `keySet()`, `values()`, `entrySet()`, `getOrDefault()` and `putIfAbsent()`

## Mini-project

Build a Student Record Manager. Store students in a list, prevent duplicate IDs, search by ID, sort by marks, find the highest scorer, calculate class average and display students by grade.

## Compile and run

```bash
javac -d out/week09 $(find week-09-collections/src -name "*.java")
java -cp out/week09 com.example.week09.records.StudentRecordManager
```
